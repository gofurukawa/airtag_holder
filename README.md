# AirTag Umbrella Holder for AMVEL pentagon LARGE

AMVEL の超軽量折りたたみ傘 [pentagon LARGE](https://www.umbrella-store.net/products/pentagon-large)（[pentagon シリーズ](https://www.umbrella-store.net/collections/pentagon-series)）の持ち手の端に、AirTag を固定するための 3D プリント用ホルダーです。

持ち手の端にある円盤を左右 2 つのパーツで挟み込み、その下に AirTag を収め、窓あきのキャップをねじ込んで全体を固定します。キャップの下に、握りを延ばす取っ手（試作）を付けることもできます。

> [!NOTE]
> AMVEL 社とは関係のない非公式の自作パーツです。寸法は手元の 1 本を実測した値で、ロットや他モデル（pentagon72 / pentagon67 など）では合わない可能性があります。

## 構造

使用時の向き（上が生地側）で、上から次の順に重なります。

| 部品 | 役割 |
| --- | --- |
| 挟みパーツ A / B | 持ち手の円盤を左右から抱き込む。上端の爪でリム上端を押さえ、下部の外周におねじ |
| AirTag | 円盤の下のポケットに収納 |
| キャップ | めねじで本体にねじ込み、左右パーツを一体化。下向きの窓（Ø26）から AirTag が見え、音も抜ける |
| 取っ手（試作・任意） | アンカーと握りの 2 部品。アンカー（T 字）の横棒を取っ手付きキャップの底の溝に落とし込み、突起を窓から外へ出す。キャップの外で握りを突起に差し込んで接着する。握りの上端はキャップの下面に突き当たり、キャップの底を横棒と握りではさむ。キャップを締めると本体の下端が横棒を押さえる |

設計上のポイントは次のとおりです。

- 円盤上面の凹みは、傘を畳むときに骨の連結部分が収まる場所なので、ふさがないようにしています。爪はリムの上端（幅約 1.35mm）だけを押さえ、凹みの開口 Ø26.8 はそのまま残ります。
- 円盤の底面は中央に向けてなだらかに膨らんでいます。実物は半径約 28mm の球面で、縁には幅約 1.5mm の平らな肩があります。空洞の底はそれよりわざと浅い球面（R33.7、縁の角と中央を通る球面）にしていて、円盤は爪・縁の角・中央の 3 か所で支えます。中央から縁の手前までに残る 0.5〜0.8mm のくさび形の空間は、印刷誤差と持ち手の個体差を吸収する余白です。実物の肩まで再現すると、空洞が設計より 0.2mm ほど狭く出るプリンタでは当たります。
- シャフト上の凹み（円盤上面から 13.5mm）や伸縮ロックのボタン（同 29.0mm）にはかかりません。
- 窓が下を向くので、入り込んだ雨水は自然に抜けます。
- 挟みパーツは合わせ面を下にして印刷するので、内側の空洞は横倒しのアーチになります。アーチの頂上（合わせ面から最も遠い所）は、45°の屋根と、元の円より 0.6mm 外側の平らな天井に置き換えています。この天井は両端が支えられた短い橋（ブリッジ）なので、サポートなしで印刷できます。少したれても、0.6mm の逃げの中に収まれば空洞には入り込みません。円盤と AirTag は、屋根の斜面と残りの円周で位置が決まります。

- 取っ手のうち窓を通るのは、アンカーの八角の突起（対辺 10mm）だけです。握りはキャップの外で差し込むので、太さや形は窓に縛られません。横棒は底の溝にはまるので回らず、上面が底と同じ高さになって AirTag を平らに支えます。
- 握りの上端はキャップと同じ Ø43.7 の平らな面で、キャップの下面に突き当たります。接着すると、キャップの底（溝の下の厚さ 2mm の部分）を上から横棒、下から握りではさむ形になり、キャップ・アンカー・握りがひとつの塊になります。握りを横に押す力は、突起の付け根ではなく、この広い突き当ての面で受けます。外形はキャップから途切れずに続き、Ø22 まで細くなるベル形なので、キャップまで含めて握れます。
- 握りは網目の殻です。中は空洞で、突起を受ける筒と殻を 4 本の縦リブでつなぎ、殻にはひし形の穴を並べています。上端の面は、キャップに当たる外周の輪と、筒へ渡す 4 本のスポークでできています。AirTag の音と、キャップに入った雨水は、窓からスポークのすき間を通って握りの中へ入り、網の穴から抜けます。詰まった握りの約半分の重さです。窓は握りで隠れるので、外から AirTag は見えなくなります。
- 握る部品なので、印刷の向きは強度で選んでいます。3D プリントの部品は、層の中より層と層の間の方が弱く、条件によっては半分程度の力ではがれます。一番細いのはアンカーの突起で、曲げる力はその付け根に集まります。アンカーは T 字の面を下に寝かせて印刷するので、どの向きに曲げても、その力を層の中で受けます。握りは上端の面を下にして立てて印刷します。
- 取っ手付きキャップは、取っ手を付けなくてもそのまま AirTag ケースとして使えます。通常のキャップより底が 3mm 厚くなります。

組み付け後の外形は、最大 Ø43.7mm、全高は約 22.5mm（円盤より下に約 11mm、上に 2mm）です。取っ手を付けると、取っ手付きキャップの下面から先端まで 40mm 延びます。

## Mac で使うソフトウェア

### OpenSCAD（.scad を開いて寸法を調整する）

```sh
brew install --cask openscad@snapshot
```

正式版（2021.01）でも動きますが、ねじ山を含むこのモデルではレンダリング（F6）に数分かかります。開発版（snapshot）を入れ、Preferences → Advanced で Backend を **Manifold** にすると数秒で終わります。Apple Silicon にもネイティブ対応しています。

Homebrew の cask 名が変わっている場合は、[openscad.org](https://openscad.org/downloads.html) の Development Snapshots から直接ダウンロードしてください。

## STL の書き出し

OpenSCAD の GUI でカスタマイザーの `part` を切り替えて F6 → F7 で書き出すか、コマンドラインで次のように実行します。

```sh
# macOS（Homebrew cask）の場合、openscad コマンドはアプリ内にある
OPENSCAD=/Applications/OpenSCAD.app/Contents/MacOS/OpenSCAD

for p in half_a half_b cap handle_cap anchor grip; do
  "$OPENSCAD" -D "part=\"$p\"" -o "$p.stl" airtag_umbrella_holder.scad
done
```

アプリ名が `OpenSCAD-Nightly.app` などになっている場合は、パスを読み替えてください。

| `part` の値 | 出力 |
| --- | --- |
| `assembly` | 傘と AirTag のダミー入りの組み付け確認用 |
| `half_a` / `half_b` | 挟みパーツ（印刷向き） |
| `cap` | キャップ（印刷向き） |
| `handle_cap` | 取っ手付きキャップ（印刷向き） |
| `anchor` | 取っ手のアンカー（印刷向き） |
| `grip` | 取っ手の握り（印刷向き） |
| `print_all` | 部品を並べた状態（`use_handle = true` なら取っ手付きキャップ・アンカー・握り、`false` なら通常のキャップ） |

`assembly` と `print_all` で取っ手を使うかどうかは、変数 `use_handle`（初期値 true）で切り替えます。

## 印刷設定（Creality Ender-3 S1 Pro + Cura 5.13 の例）

Cura のプロファイル「Standard Quality」を元に、次のように設定します。括弧内は Cura の英語表示の項目名で、設定パネル上部の検索欄に入れると見つかります。

| 設定 | 値 | 理由 |
| --- | --- | --- |
| ノズル径（Nozzle） | 0.4 mm | 標準 |
| 積層ピッチ（Layer Height） | 0.16 mm | ねじ山をなめらかにする |
| 壁の線数（Wall Line Count） | 4 | ねじ部（肉厚約 1.8mm）をほぼソリッドにする |
| インフィル密度（Infill Density） | 20%（初期値のまま） | 壁 4 本で部品のほとんどが埋まり、インフィルが入る所はほとんどない（下記） |
| サポート（Generate Support） | オフ | どの部品もサポートなしで印刷できる。オンにすると空洞の平らな天井の下にサポートが入る |
| ブリッジ設定（Enable Bridge Settings） | オン | Standard Quality では初期値がオフ。オンにすると、空洞の天井（ブリッジ）だけ速度と冷却を調整し、糸を張るように渡す |
| ブリッジのファン速度（Bridge Fan Speed） | 100% | ブリッジ設定をオンにすると表示される。渡した糸をすぐ固めて、たれを抑える |
| 初期層水平展開（Initial Layer Horizontal Expansion） | -0.1〜-0.2 mm | 1 層目がつぶれて広がり（エレファントフット）、合わせ面のふちが空洞側やねじ側へはみ出すのを防ぐ |
| 向き | STL のまま | 挟みパーツは合わせ面が下（ねじ山が上）、キャップは底面が下、アンカーは T 字の面が下、握りは上端の面が下 |

- 挟みパーツは合わせ面を下にして印刷します。下を向く面は空洞の 45°の屋根と短い橋、ピン穴の小さな天井だけなので、サポートは要りません。合わせ面がベッドで平らに仕上がり、定着も安定します。
- この向きだと、ねじ山と爪にかかる力（ねじの軸方向）が積層面に沿うので、層間で割れにくくなります。
- ピン穴はベッドから垂直に立つ穴になり、真円に出ます。
- 空洞の天井は、PrusaSlicer 2.7 でスライスするとブリッジとして処理され、渡す長さは次のとおりでした。円盤の空洞は四方が囲まれているので、スライサーが短い向き（ねじの軸方向）を選びます。

  | 天井 | 渡す向き | 長さ |
  | --- | --- | --- |
  | AirTag ポケット | ねじの軸と直角 | 約 12 mm |
  | 円盤の空洞 | ねじの軸方向 | 約 6 mm |
  | 爪の開口 | ねじの軸と直角 | 約 10 mm |

- ブリッジの下面（空洞の内側）は糸が少したれたり波打ったりしますが、円盤や AirTag には触れない面なので、そのままで構いません。たれが 0.6mm を超えて円盤や AirTag が窮屈になるときは、`bridge_relief` を増やします（下の「調整」を参照）。
- キャップはサポートなしで印刷できます。取っ手付きキャップの溝は上向きに開いているので、これも同じです。
- アンカーは T 字の面を下に寝かせて印刷します。突起の断面は八角形なので、ベッドに付く面の両隣は 45°の斜面になり、サポートは要りません。逃げ溝は上を向きます。
- 握りは上端の面（Ø43.7）を下にして立てて印刷します。ベッドから細くなっていく斜面は垂直から 40°以内、網目のひし形の穴は上の角が 45°、受け筒の奥は 45°の屋根、先端は上を向いた半球なので、サポートは要りません。接地面が広いので、ブリムも要りません。
- 網目の桟は 2mm 前後と細いので、PLA だと強く握ったり落としたりしたときに割れることがあります。常用するなら、粘りのある PETG がおすすめです。網目の桟とリブ・受け筒はほぼ壁だけでできるので、インフィルの設定はほとんど効きません。
- インフィル密度はほぼ効きません。PrusaSlicer 2.7 で壁 4 本・インフィル 20% でスライスすると、インフィルの割合は使うフィラメントの 0.1%（挟みパーツ）と 5%（キャップ）でした。50% に上げても挟みパーツは変わらず、キャップが 4% 増えるだけです。
- 素材は、試し刷りなら PLA で十分です。常用するなら、熱や紫外線に強い PETG か ASA がおすすめです。PETG は PLA よりブリッジがたれやすいので、ブリッジの速度を落とすと安定します。

## 組み立て

1. 1.75mm フィラメントをニッパーで約 6mm に 2 本切り、バリを落とします。
2. 挟みパーツの片方の合わせ面にあるピン穴に、ピンを差し込みます。
3. 左右のパーツで持ち手の円盤を挟みます。
4. 下側のポケットに AirTag を入れます。
5. キャップをねじ込みます。キャップは本体の下端に突き当たって止まり、AirTag を押しつぶしません。

取っ手を付けるときは、上の手順 5 の前に次のようにします。

1. 取っ手付きキャップを単体で持ち、アンカーを突起の先からキャップの内側（ねじ側）に入れ、窓から外へ通します。
2. 横棒を底の溝に落とし込みます。横棒の上面が底と同じ高さになれば、正しく収まっています。
3. 握りの穴に接着剤を入れ、窓から出ている突起に握りを差し込みます。突起の逃げ溝から空気と余った接着剤が抜けます。握りの上端がキャップの下面に突き当たるまで押し込みます。このとき横棒が溝から浮かないよう、キャップの内側から横棒を押さえたまま、固まるまで押さえます。握りの上端の面とキャップの下面の間にも接着剤を薄く塗ると、さらにがたつきません。接着剤は、PLA なら瞬間接着剤（ゼリー状）か 2 液性エポキシ、PETG なら 2 液性エポキシがおすすめです。
4. はみ出した接着剤は、固まる前にふき取ります。窓のふちやキャップの底に付くと、AirTag の窓をふさいだり、横棒が溝から浮いたりします。
5. 取っ手を押さえたまま、取っ手付きキャップを本体にねじ込みます。本体の下端が横棒を上から押さえて固定します。

接着した後も、取っ手付きキャップは本体から回して外せるので、AirTag の電池交換はこれまでどおりできます。

## 調整

試し刷りの結果に応じて、`.scad` の次の変数を変えてください。

| 症状 | 変数 | 目安 |
| --- | --- | --- |
| キャップがきつい／緩い | `thread_clr`（初期値 0.35） | きつければ 0.45、緩ければ 0.25 |
| 円盤にはめるとガタつく／閉じない | `clr`（初期値 0.2）、`recess_d`（爪の内径） | 0.1 刻みで調整 |
| 空洞の底を実物の肩まで再現したい | `dome_R`（初期値 0 ＝ 自動で 33.7、平らな肩なし） | 28 にすると実物に近い球面と幅約 1.4mm の平らな肩になる。中央から縁の手前までのすき間が 0.3〜0.4mm に減るので、空洞が狭く出るプリンタでは当たることがある。当たるなら 30〜31 |
| 空洞の天井が大きくたれる | `bridge_relief`（初期値 0.6） | 0.8 まで増やせる（ねじの谷までの肉厚が 1.0mm に減る）。0 にすると真円に戻り、横倒しで印刷するときは天井にサポートが要る |
| ピンがきつい／抜ける | `pin_clr`（初期値 0.08） | きつければ 0.12、緩ければ 0.05 |
| AirTag がカタカタ鳴る | — | 厚さ 0.5mm 程度のシリコンシートを挟む |
| キャップが緩みやすい | `washer_gap`（初期値 1.0） | ねじ上端の段差に平ワッシャー状のシリコンパッキンを入れる |
